총공 빌더 자동검색 버전 - 처음부터 따라하기

이 버전은 여러 사람이 링크로 접속해서 쓰는 웹사이트용입니다.
SID 자동검색을 위해 서버가 필요해서 Netlify 단순 드래그 업로드가 아니라 Vercel 배포를 사용합니다.

중요한 점
1. 유튜브는 비교적 잘 검색됩니다.
2. 멜론/지니/벅스/바이브는 사이트에서 차단하거나 구조가 바뀌면 자동검색이 실패할 수 있습니다.
3. 실패한 칸은 화면에서 직접 입력할 수 있게 만들어두었습니다.
4. 이 프로그램은 로그인/불법 우회/캡차 우회를 하지 않습니다.

-----------------------------------
A. 준비물 설치
-----------------------------------
1. Node.js 설치
   - 네이버에서 Node.js 검색
   - LTS 버전 설치

2. GitHub 계정 만들기
   - github.com 가입

3. Vercel 계정 만들기
   - vercel.com 가입
   - GitHub 계정으로 가입하면 편합니다.

-----------------------------------
B. 내 컴퓨터에서 먼저 실행하기
-----------------------------------
1. 이 폴더를 압축 해제합니다.
2. 폴더 빈 곳에서 Shift + 마우스 오른쪽 클릭
3. '터미널에서 열기' 또는 'PowerShell에서 열기' 클릭
4. 아래 명령어를 한 줄씩 입력합니다.

npm install
npx vercel dev

5. 브라우저 주소창에 아래 주소를 입력합니다.

http://localhost:3000

-----------------------------------
C. 사람들과 공유하는 사이트로 올리기
-----------------------------------
가장 쉬운 방법은 GitHub에 올린 다음 Vercel로 연결하는 것입니다.

1. GitHub에서 새 저장소 만들기
   - 이름 예: gong-builder-auto

2. 이 폴더 안의 모든 파일을 GitHub 저장소에 업로드
   - api 폴더
   - public 폴더
   - package.json
   - vercel.json

3. Vercel 접속
   - Add New Project 클릭
   - GitHub 저장소 선택
   - Deploy 클릭

4. 배포가 끝나면 주소가 생깁니다.
   예: https://gong-builder-auto.vercel.app

5. 그 주소를 총공팀원들에게 공유하면 됩니다.

-----------------------------------
D. 사용법
-----------------------------------
1. 곡명/가수명 입력
2. SID 자동검색 클릭
3. 빈칸이 있으면 직접 보충
4. 시간, 갤주소, 총공 제목 입력
5. 총공 추가 클릭
6. Copy 또는 To Image 클릭

-----------------------------------
E. 자동검색이 안 될 때
-----------------------------------
멜론/지니/벅스/바이브는 사이트가 자동접속을 막을 수 있습니다.
그 경우 프로그램 고장이 아니라 해당 사이트가 막은 것입니다.
이때는 빈칸에 직접 SID를 넣으면 됩니다.
